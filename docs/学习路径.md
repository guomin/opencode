# 学习路径指南

这是一份完整的学习路径，帮助你系统地掌握OpenCode项目。

## 🎯 学习目标

通过学习这些文档，你将能够：
1. 理解OpenCode的整体架构
2. 掌握Session系统的核心概念
3. 理解LLM流式输出的处理机制
4. 掌握事件系统的工作原理
5. 能够独立地添加新功能或修复bug

## 📚 推荐学习顺序

### 第一阶段：基础理解（1-2周）

#### Week 1: 架构和Session
- [01-项目架构](../01-项目架构/) - **先看这个！**
- [02-Session系统](../02-Session系统/) - **核心概念**

**学习重点**：
- 理解项目的目录结构
- 理解Session、Message、Part的关系
- 理解Session的生命周期

**实践活动**：
```bash
# 运行CLI
opencode run "创建一个README.md"

# 查看生成的文件
ls ~/.opencode/storage/session/
ls ~/.opencode/storage/message/
ls ~/.opencode/storage/part/
```

---

#### Week 2: LLM和事件
- [03-LLM流式输出](../03-LLM流式输出/)
- [04-事件系统](../04-事件系统/) - **重要！**

**学习重点**：
- 理解流式输出的流程
- 理解事件驱动的架构
- 理解Part更新如何触发UI刷新

**实践活动**：
```bash
# 观察JSON事件流
opencode run "测试" --format json

# 查看存储的Part
cat ~/.opencode/storage/part/{messageID}/part_*.json
```

---

### 第二阶段：深入理解（2-3周）

#### Week 3: 工具和权限
- [05-工具系统](../05-工具系统/)
- [06-权限系统](../06-权限系统/)

**学习重点**：
- 理解工具的定义和调用
- 理解权限控制机制
- 理解为什么子session权限更严格

**实践活动**：
```bash
# 查看所有可用工具
opencode agent list

# 查看agent的权限
opencode agent show <agent-name>
```

---

#### Week 4: UI和高级特性
- [07-CLI和UI](../07-CLI和UI/)
- [08-高级特性](../08-高级特性/)

**学习重点**：
- 理解CLI如何订阅事件
- 理解UI实时更新机制
- 理解Session压缩、撤销等高级功能

**实践活动**：
```bash
# 启动Web UI
opencode serve

# 在另一个终端执行
opencode run "测试"

# 观察Web UI的实时更新
```

---

## 💡 学习技巧

### 1. 代码阅读技巧

**使用IDE功能**：
- **查找引用**：右键函数 → "Find References"
- **跳转定义**：Ctrl+点击函数名
- **搜索**：Ctrl+Shift+F（全局搜索）

**推荐工具**：
- **grep/rg**：搜索代码
- **fzf**：模糊搜索文件
- **bat/exa**：更好的cat/ls

### 2. 调试技巧

**启用详细日志**：
```bash
LOG=debug opencode run "测试"
```

**查看存储**：
```bash
# 实时监控storage目录
watch -n 1 'ls -la ~/.opencode/storage/session/*/'
```

**使用JSON格式**：
```bash
opencode run "测试" --format json | jq '.'
```

### 3. 理论+实践结合

**学习循环**：
```
1. 阅读文档理解概念
   ↓
2. 运行CLI观察行为
   ↓
3. 查看生成的文件
   ↓
4. 阅读相关源代码
   ↓
5. 动手修改/扩展
   ↓
6. 回到步骤1，深入理解
```
